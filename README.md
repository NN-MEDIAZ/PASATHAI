# 🇹🇭 เกมเรียนรู้พยัญชนะไทย ๔๔ ตัว (Thai Alphabet Interactive Learning)

เว็บแอปพลิเคชันเพื่อการเรียนรู้และเกมฝึกทายพยัญชนะไทย ๔๔ ตัว (ก-ฮ) สีสันสดใส สวยงาม พร้อมเสียงอ่านและภาพประกอบการ์ด 3D เล่นได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## ✨ คุณสมบัติเด่น (Features)
- 👆 **โหมดแตะเรียนรู้ (Explore Mode):** แตะเพื่อฟังเสียงอ่านพยัญชนะ (ก ไก่, ข ไข่, ...)
- 🎴 **การ์ดสามมิติ (3D Flip Card):** แตะค้างเพื่อเปิดการ์ดดูรูปภาพและบทกลอนท่องจำเต็มรูปแบบ
- 🎯 **เกมทายพยัญชนะ (Quiz Mode):** สุ่มโจทย์เสียงให้อัตโนมัติ พร้อมระบบนับคะแนนและคอมโบต่อเนื่อง
- 🎵 **โหมดท่อง ก-ฮ (Karaoke Mode):** เลื่อนอ่านและเล่นเสียง ก-ฮ ทีละตัวแบบอัตโนมัติ
- 🌈 **ปรับแต่งธีมและเสียงได้:** มี 5 ธีมสีสันสดใส และปรับความเร็วเสียงอ่านได้
- 📱 **รองรับทุกหน้าจอ (Responsive):** แสดงผลสวยงามบนมือถือ แท็บเล็ต และคอมพิวเตอร์

---

## 🚀 วิธีเปิดใช้งานบน GitHub Pages (เล่นออนไลน์ฟรี)

1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ทางด้านซ้าย
3. ในส่วน **Build and deployment > Source** เลือก `Deploy from a branch`
4. ในช่อง **Branch** เลือก `main` (หรือ `master`) และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที จะได้ลิงก์เว็บไซต์ เช่น `https://<ชื่อของคุณ>.github.io/<ชื่อโปรเจกต์>/` เพื่อเปิดเล่นและแชร์ให้ผู้อื่นได้ทันที!

## 📁 โครงสร้างโปรเจกต์
```text
├── index.html        # หน้าเว็บหลัก
├── index.css         # ไฟล์สไตล์ตกแต่งและอนิเมชัน
├── app.js            # ระบบควบคุม UI, เกมทายคำ, และอนิเมชัน
├── speech.js         # ระบบเสียงอ่านพยัญชนะภาษาไทย
├── audio_synth.js    # ระบบเสียงเอฟเฟกต์ (SFX)
├── thai_data.js      # ฐานข้อมูลพยัญชนะไทย กลอน และหมวดหมู่
├── assets/
│   ├── cards/        # รูปภาพการ์ดพยัญชนะไทย 44 ตัว
│   └── audio/        # ไฟล์เสียงอ่านพยัญชนะ
└── README.md         # เอกสารแนะนำโปรเจกต์
```
